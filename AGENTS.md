# TTQ development guide

`src/` is the source of truth. `dist/ttq.user.js` is the checked-in Tampermonkey artifact generated by `npm run build`.

Before editing, read [PROJECT.md](PROJECT.md). For the current milestone and decisions, read [STATE.md](STATE.md). Consult [docs/architecture.md](docs/architecture.md) before moving code between source fragments.

## Workflow

1. Change the smallest relevant file in `src/`.
2. Run `npm run check`; it rebuilds the installable userscript and validates its JavaScript syntax.
3. For behavior changes, install `dist/ttq.user.js` in Tampermonkey and verify the affected Travian screen manually.
4. Commit relevant source, documentation, and the regenerated distribution artifact together.

## Runtime constraint

The userscript relies on legacy shared state. The build preserves one closure and concatenates source files in the order declared in `scripts/build.mjs`. Treat that order as part of the runtime interface; add a source file only when its dependencies are already available.
